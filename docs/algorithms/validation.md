# Validation and tolerances

Every algorithm is compared with Crystal-Builder or sci-form golden data. The
tolerances below are the initial contract; a test that needs a wider tolerance
must record the reason in the algorithm page.

| Feature | Comparison | Tolerance | Phase |
|---|---|---|---|
| Element reference data | exact | 0 (copied from Crystal-Builder) | 1 |
| Cell parameters | absolute | 1e-6 Angstrom / 1e-6 degree | 1 |
| Cell volume | relative | 1e-9 | 1 |
| Fractional coordinates | absolute | 1e-6 | 1 |
| Atom sets | up to translation and permutation | 1e-6 fractional | 1 |
| Bond length | absolute | 1e-4 Angstrom | 1 |
| Bond order | absolute | 1e-3 | 1 |
| Bond count | exact | 0 (MOF-5 and Si golden) | 1 |
| Ring size/count | exact | 0 | 1 |
| Minimum-image distance | absolute | 1e-9 Angstrom | 1 |
| CIF cell parameters | absolute | 1e-6 Angstrom / degree | 1 |
| CIF atom count | exact | 0 | 1 |
| POSCAR/XYZ round trip | absolute | 1e-9 Angstrom | 1 |
| Neighbor distance | absolute | 1e-9 Angstrom | 1 |
| Slab atoms per layer | exact | 0 | 1 |
| Ring paths | atom indices and images | exact after atom mapping | 1 |
| Functional groups | atom sets | exact after atom mapping | 1 |
| Space group number / Hall number | exact | exact | 2 |
| Wyckoff letters | exact | exact | 2 |
| Standardized cell | absolute | 1e-5 Angstrom / 1e-4 degree | 2 |
| K-path | points and labels | 1e-6 fractional | 2 |
| PXRD positions | absolute | 0.01 degree 2-theta | 5 |
| PXRD intensities | absolute after normalization | 1e-3 | 5 |
| UFF energy | absolute | 1e-6 eV per atom | 4 |
| UFF forces | absolute | 1e-4 eV/Angstrom | 4 |
| UFF stress | absolute | 1e-3 GPa | 4 |
| Charges | absolute | 1e-6 e | 4 |
| Porosity | absolute | 0.01 Angstrom / 0.1 percent | 5 |
| Topology | canonical graph | exact | 5 |

## Rules

- The comparison helpers live in `xtalforge-testkit` (Task 0.9.4).
- Golden files are generated by `scripts/golden/` and never by CI.
- A deliberate deviation from Crystal-Builder is recorded in the algorithm
  page with the reason and the affected structures.
- Tightening a tolerance is a normal change; widening one requires a note in
  the changelog and in the algorithm page.
