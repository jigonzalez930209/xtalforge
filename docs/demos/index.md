# Demos

Interactive demos run the WebAssembly build directly in the page:

- [3D playground](../playground): load, transform and build structures and
  inspect them in three dimensions.
- [Cell volume](./cell-volume): the hello-world slice, running fully offline.
- [CIF inspector](./cif-inspector): cell, formula, density, bonds, rings,
  downloadable supercells and slabs.
- [Structure editor](./editor): undo/redo, command history and CIF export
  through the WebAssembly document.
