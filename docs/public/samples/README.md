The measured-pattern sample `rutile-cuka.xy` is a byte-identical copy of
`tests/golden/phase-7/rietveld/rutile.xy`: synthetic rutile (`a = 4.5940`,
`c = 2.9590`, O at `x = 0.29`), Cu K alpha 1 + K alpha 2, 20-80 degrees with
Poisson noise (seed 0), generated by the Crystal-Builder `_rutile_xy` fixture
(MIT); it feeds the playground refinement panel.

The full provenance and citations are in `tests/corpus/PROVENANCE.md`.
`tests/e2e/reference/generate.py --check-samples` fails when a copy drifts
from its corpus source.
