# RCSR facts (Task 14.4.2)

`rcsr_facts.tsv.gz` is the searchable half of the RCSR catalogue: periodicity,
coordination numbers, the Hermann-Mauguin group the RCSR writes the net in,
and the Blatov transitivity `p q r s` (kinds of vertex, edge, face and tile).

## Compression (Task 15.3.2)

The crate embeds the gzip file and decompresses it on first use, after
verifying its SHA-256 checksum:

```bash
gzip -dc rcsr_facts.tsv.gz | sha256sum
```

The manifest constant lives in `../src/netsearch.rs`. `icsd_bv.json.gz` and
`rcsr_index.bin.gz` use the same scheme; the smaller `bvparam_1991.json`,
`it92.json` and `neutron.json` stay embedded uncompressed because gzip would
save less than 4 KiB in total.

## Provenance

Generated from the two snapshots bundled in the repository's `data/rcsr/`
directory (see `data/rcsr/README.md`):

| Source | What it supplies |
|---|---|
| `rcsr-2019-06-01.json.gz` | name, periodicity, coordination sequences, group symbol |
| `rcsr-transitivity-2026-09-24.json.gz` | `p q r s` of every net the RCSR lists |

The coordination numbers are the first term of each distinct coordination
sequence. A net with no entry in the transitivity file falls back to the
`NODE` and `EDGE` counts of the catalogue row for `p` and `q`, and leaves `r`
and `s` empty; a layer always has `s` empty because it has no tiles.

## Columns

One tab-separated row per net, in catalogue order, after the `#` header:

```
name  periodicity  coordination  group  p  q  r  s
```

`coordination` is a comma-separated list. An empty transitivity field means
unknown. Group symbols are the RCSR's own spellings; the crate resolves the
space-group number at load time through `xtalforge-symmetry`, and a layer
through its plane-group number (1 to 17).

## Regenerating

The snapshots are the canonical data; the table is a derived view. Rebuild it
with the same transformation as the generator used when the snapshots change:

```python
import gzip, json
cat = json.load(gzip.open("data/rcsr/rcsr-2019-06-01.json.gz", "rt"))
trans = json.load(gzip.open("data/rcsr/rcsr-transitivity-2026-09-24.json.gz", "rt"))["nets"]
for row in cat["nets"]:
    name, periodicity, sequences, _symbols, group, nv, ne = row[:7]
    coordination = sorted({sequence[0] for sequence in sequences if sequence})
    p, q, r, s = trans.get(name, (int(nv) or None, int(ne) or None, None, None))
    print("\t".join([name, str(periodicity), ",".join(map(str, coordination)),
                     group, p or "", q or "", r or "", s or ""]))
```

The first three `#` lines of the file are regenerated by hand with the same
text. The crate never mutates the table at runtime.
